# Troubleshoot local profiles and progress

## I cannot sign in on another device

Accounts are local. Creating a profile on one installation does not create it on
another. There is no cloud account sync. Desktop storage and browser storage also
remain separate on the same device.

## I forgot my password

The app does not provide email-based password recovery. Do not expect a reset
email. Avoid deleting application data as a first response: it can remove progress.
Keep exported backups of study progress before changing installations.

## My browser progress appears missing

Confirm you are using the same browser profile, hostname, and port. A different
origin has separate storage. Clearing site data removes local progress. Check
whether the data is in the desktop app rather than the browser.

## I need to move progress

Use the app's **Data & sources** area to export progress as JSON. Preserve the
export before importing on another installation. Import validates the data and
requires confirmation before replacing current progress. Review the warning and
keep a backup of the destination profile first. Passwords are not part of progress exports.

## An exam expired while the app was closed

Timed attempts use an absolute deadline. Closing or hiding the app does not pause
the timer. Reopening finalizes an expired attempt. Keep the operating-system clock
correct and use untimed practice when you need to pause.

## A source link is unavailable offline

The local study material can work offline; external AWS documentation still needs
internet. The project includes dated source-review records, not a guarantee that
every external service detail remains current.
