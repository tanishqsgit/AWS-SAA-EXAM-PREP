What is Amazon Translate? Amazon Translate is a text translation service that uses advanced machine learning technologies to provide high-quality translation on demand. You can use Amazon Translate to translate unstructured text documents or to build applications that work in multiple languages. Translate interpersonal communications, such as email, in-game chat, customer service chat, so that customers and employees can connect in their preferred language. Enable language-independent processing by integrating Amazon Translate with other AWS services: Extract named entities, sentiment, and key phrases from unstructured text, such as social media streams with Amazon Comprehend . Translate text stored in the following databases: Amazon DynamoDB , Amazon Aurora , and Amazon Redshift . Seamlessly integrate workflows with AWS Lambda or AWS Glue .
